# Galaxy for Android

**Galaxy** is the Android companion app for StarPilot. Its Google Play listing name is **Galaxy: StarPilot Companion**.

The Android app source is provided under the repository's MIT license. See the repository root `LICENSE` for its terms.

## Privacy policy

The [privacy policy](docs/privacy-policy.md) describes the app's permissions, local storage, optional location sharing, Bluetooth pairing, and mobile data use. The rendered Markdown page can be used as the policy webpage if the repository is public and the page is accessible without signing in. Use its stable HTTPS URL in the Google Play Console privacy policy field, and make the policy reachable from within the app before publishing.
